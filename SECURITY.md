# Security Policy

## Reporting a vulnerability

Please **do not** open a public issue for security problems.

Email **muhammad.waris9@icloud.com** with:

- what you found and where,
- the steps to reproduce it,
- the impact you believe it has.

You'll get an acknowledgement within 72 hours and an assessment within 7 days.
Please give us a reasonable window to ship a fix before disclosing publicly.

## Supported versions

Only the code currently deployed from `main` is supported.

## Scope

In scope: this application's own code and configuration.

Out of scope: findings against the shared hosting platform itself, missing
headers on third-party domains, volumetric denial-of-service, and reports
generated purely by automated scanners without a demonstrated impact.
